# RUNCARD 2026-10-31: topology on gw26, by hand

For whoever has a shell on gw26 (Debian 13, per the c4-ACTUAL instructions: `6.12.95+deb13-amd64`).
Each step says what to run and what you should see. Stop at any step whose check does not hold;
nothing later depends on guessing.

This session could reach gw26 only over HTTPS (`https://gw26.bru.st/` answered `200` from nginx
on 2026-10-31); it had no SSH, so none of this has been run there yet.

## 1. Build (on gw26, or anywhere with Debian 13 and the build tools)

```
sudo apt install build-essential debhelper help2man git nodejs
git clone -b corwin https://github.com/inputloop/topology.git && cd topology
sh bin/fetch-sources.sh                 # see: ok vendor/perl/perl-5.44.0.tar.gz
sh bin/test.sh /usr/bin/perl            # needs Feature::Compat::Class; or skip to the build, which tests with its own perl
dpkg-buildpackage -us -uc               # about 15 minutes on two cores
ls ../topology*_0.01*.deb               # see: three .deb files
```

## 2. Install, smallest first

```
sudo apt install ../topology-www_0.01_all.deb
ls /usr/share/topology/www/index.html   # the app, as files: the "spa" rung
sudo apt install ../topology-perl_0.01_amd64.deb ../topology_0.01_all.deb
topology --version && topology config   # see every feature and the line that decided it
systemctl status topology-api           # active, or skipped with "need api" if switched off
```

## 3. The front door

Add to the nginx server block that answers for gw26.bru.st:

```
include /usr/share/topology/nginx/topology.conf;
```

then `sudo nginx -t && sudo systemctl reload nginx`. Check: `curl -s https://gw26.bru.st/ | grep -c 'Start now, share nothing'` prints 1, and `curl -s https://gw26.bru.st/api/v1/` prints JSON with `"write":false`.

If gw26's current homepage should stay reachable, move it under a path first; this include sets the root.

## 4. Repositories

One file per repository in `/etc/topology/repos.d/` (see the README there). For a private GitHub
repository, a fine-grained read-only token in `/etc/topology/keys/NAME.token`, mode 0600, owner
topology; or a deploy key. Then:

```
sudo -u topology topology repos         # every line ends in "ok"
sudo systemctl start topology-refresh   # fetch and build once
sudo -u topology topology check         # "every cell agrees on both sides"
```

## 5. Downloads

```
sudo sh bin/publish-dist.sh .. /var/lib/topology/dist
curl -s https://gw26.bru.st/dist/index.json | head -c 200
```

## 6. Back to just the files

To take it all back to the "spa" rung without removing anything:

```
echo 'ceiling = spa' | sudo tee -a /etc/topology/topology.conf
sudo systemctl restart topology-api     # now skipped: "'api' is off (above the ceiling (spa))"
```
