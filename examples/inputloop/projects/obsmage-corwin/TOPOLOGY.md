# obsmage-corwin

A personal recipe repository that consumes `obsmage`. It is private: this page says only that it exists.

## Private

One person's OBS rig, as recipe and atoms: `RECIPE.md`, `SCENES.md`, `STAGES.md`, `atoms/`, `journal/`,
and `hosts/avalon` and `hosts/giza` (the giza port is parked). Credentials are `secret` atoms and never
appear in the tree. Read `CONVENTIONS.md` of obsmage and `RECIPE.md` here before changing how things are kept.
