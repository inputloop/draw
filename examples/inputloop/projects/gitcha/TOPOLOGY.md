# gitcha

A free, self-hosted forge for people and their agents: packages, git hosting, site hosting, CI and
functions, with two-factor sign-in on every account and a Claude extension that speaks it. It is the
front door of inputloop.com; the software is called Gitcha, which is why its commands and settings say
`gitcha`. Made by Bryant and Corwin. The repository is public (since 2026-11-01); its README says
which parts have been tested only against stand-ins.
