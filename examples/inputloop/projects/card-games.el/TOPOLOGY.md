# card-games.el

About thirty card games for GNU Emacs, from Klondike and FreeCell to Hearts, 500, Gin, Cribbage and
two-player Russian Bank against the computer. Every game plays from the keyboard, and with the mouse on a
graphical display. Cards are drawn as SVG on a graphical display and as Unicode glyphs in a terminal; a
menu switches the treatment and the computer's skill. 500 can be played live over the network. It ships
an Info manual.

Corwin's own, kept under his own GitHub account (mplscorwin) rather than the inputloop org. Installed
from MELPA: `M-x package-install RET card-games RET`. Code GPL-3.0-or-later; manual CC-BY-4.0, as its
README gives them (read 2026-11-01).
