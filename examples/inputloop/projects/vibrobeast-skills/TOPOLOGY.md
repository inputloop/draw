# vibrobeast-skills

Written ways of working that Claude reads when a task calls for them; each skill is also a slash
command. 78 skills, counted 2026-10-30. Installs into Claude Desktop or Claude Code as a plugin. Each
skill says when it applies, what it does, how it can fail and how to switch it off; several carry
checks that are shown able to fail before anyone trusts them.
