# avalon

Corwin's workstation, and the machine most of the shop's work is started and signed on. The Windows side of the shop (Emacs for Windows builds, MSYS2 shells, the folder the agents land work in) lives here.

The app can draw it as a `server`. It is not reachable from outside; nothing here depends on that changing.
