# inputloop

The shop Corwin Brust and Bryant Frankford keep together, with Brigidt (GitHub: definitelynotaspren)
as a lab partner. This folder draws it the way topology wants to: one `TOPOLOGY.md` per thing, in four
kinds of container.

| pillar | what it holds here | folder |
|---|---|---|
| place | the hosts the work runs and lives on | `hosts/` |
| part | projects, components, files and tools | `projects/` |
| path | how work moves: mirroring, tangling, the atoms round trip | `paths/` |
| person | who answers for what | `people/` |

Three projects are private (`obsmage`, `obsmage-corwin`, `c4`). Each says `private: hide`
and keeps what it holds under a `## Private` heading, so the drawing names them and nothing more until
someone chooses to show them. The rule is in `spec/TOPOLOGY-md.md`.

Where a fact is not yet written down, the file says so instead of guessing.
