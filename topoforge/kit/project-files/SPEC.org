What this kit holds the shell scripts in =bin/= to.  The scripts are POSIX
sh; the checker, =check.py=, is Python (standard library only), so a fault
shared by one language's habits is less likely to pass both.  Run:

: PYTHONDONTWRITEBYTECODE=1 python3 -I kit/project-files/check.py

Exit 0 every rule holds; 1 a rule is broken; 2 the kit itself is broken
(it could not run, or a planted fault went unnoticed).

* T  Tangling (=bin/tangle.sh= and =RECIPE.org=)
- T1 A source block is tangled when its =#+begin_src= line (any case) names
  =:tangle PATH= and PATH is not =no=.  Its body is every line up to the next
  =#+end_src=, with one leading comma removed from a line that starts =,*=
  or =,#+=.  When the line names =:shebang "S"=, S is written first.  Every
  written line ends in one newline.
- T2 A second reader written to T1 (in =check.py=) and =bin/tangle.sh= give
  byte-equal files for every block in =RECIPE.org=.
- T3 The committed =bin/*.sh= are byte-equal to what T2 produces: the scripts
  have not drifted from the recipe.
- T4 =bin/tangle.sh= refuses (exit 2) a path that is absolute, holds =..=, or is
  named by two blocks.

* S  Sums (=bin/sums.sh=)
- S1 Each line is 64 lowercase hex digits, two spaces, the path relative to
  the project root; the digest is the file's SHA-256.
- S2 Lines are sorted by path in byte order, each path once; the output
  file never lists itself.
- S3 A missing named file: exit 1, and the output file is left as it was.
- S4 =--check= exits 0 when every listed file matches and 1 when one differs.

* V  Verify (=bin/verify.sh=)
- V1 Exit 0 when =upstream/topoforge-1.5.html= has sha256
  =6a76e9ca66e6a2733a35677c11599114b4009529568580526d90427fa08a9e2a= and
  =SHA256SUMS= (if present) matches; exit 1 when either differs.

* R  Prove red
The kit plants faults and must see each one go red, or it reports KIT BROKEN
and exits 2:
- R1 a copy of =sums.sh= whose =sort -u= is replaced by =cat= (S2 must fail);
- R2 a copy of =sums.sh= that sums with =md5sum= (S1 must fail);
- R3 a copy of =RECIPE.org= with one line of a block changed (T3 must fail);
- R4 an upstream copy with one byte changed (V1 must fail).
